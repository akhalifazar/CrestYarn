CrestYarn provides a High-Performance, Scalable framework for real-time yarn data processing and engine optimization.

## Installation

1. Clone the repository: `git clone https://github.com/minhokingkim/CrestYarn.git`
2. `cd CrestYarn`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure CrestYarn, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
